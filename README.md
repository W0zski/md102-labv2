# Microsoft Intune / MD-102 – Teknisk portfolio

**Erik Fors**

Det här repot innehåller praktiska projekt från en egen Microsoft 365-testmiljö med fokus på Microsoft Intune, Microsoft Entra ID och Windows 11. Projekten visar hur konfigurationer skapas, tilldelas, distribueras och verifieras på klienten.

## Projekt

| Projekt | Område | Vad som demonstreras |
|---|---|---|
| [01 – Windows Autopilot](./01-Windows-Autopilot/) | Provisionering | Hardware hash, användardriven Autopilot, Entra join, ESP, OOBE, Windows Hello, verifiering |
| [02 – BitLocker & Windows LAPS](./02-BitLocker-LAPS/) | Endpoint security | BitLocker, TPM/startup-policy, recovery, Windows LAPS, automatic account management, assignment filters |
| [03 – Win32 App Deployment](./03-Win32-App-Deployment/) | Applikationshantering | .intunewin, silent install/uninstall, requirements, detection rules, required assignment, verifierad installation |

## Miljö

- Microsoft Intune
- Microsoft Entra ID
- Windows 11
- Hyper-V testmiljö
- Microsoft 365 testtenant

## Fokus

Portfolion är byggd för att visa praktisk förståelse för endpoint management: från en ny Windows-enhet till säkerhetskonfiguration, lokal administratörshantering och applikationsdistribution.

> Testmiljön används endast för labb och utbildning. Konton, enhetsnamn och identifierare som syns i bilderna tillhör testmiljön.
